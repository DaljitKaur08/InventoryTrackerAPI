# InventoryTrackerAPI

## Project Description

This Web API is designed to manage inventory data including products, categories, suppliers, and orders. It allows users to perform CRUD operations and track inventory efficiently.

## Features

* Create, Read, Update, Delete products
* Manage categories and suppliers
* Track inventory quantities
* RESTful API endpoints
* Swagger API documentation

## Technologies Used

* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* Swagger / OpenAPI

## How to Run

1. Clone the repository
2. Open project in Visual Studio
3. Run the application
4. Use Swagger UI to test endpoints

## API Endpoints

* GET /api/Product
* POST /api/Product
* PUT /api/Product/{id}
* DELETE /api/Product/{id}
